---

Richtfest brings people, projects and agents into one workspace. Customers and project records provide context; source files and reviewed knowledge preserve evidence; conversations and tasks coordinate the work.

## First prototype

The first workflow is onboarding a real customer project: attach source material, discuss open questions, assign work, prepare source-linked knowledge and have a person approve it. The next domain workflow is external sound-insulation assessment, using a completed reference project to validate results.

This prototype is under active implementation. Connected-provider execution, automated extraction, video transcription and engineering calculations are separate capabilities; a stored credential or uploaded file does not mean those capabilities have run.
